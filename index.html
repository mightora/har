How To

How to Capture a HAR File

A HAR (HTTP Archive) file records all network activity in your browser. Follow these steps to capture one.

🌐

Google Chrome

  1. Open Chrome DevTools: press F12 or Ctrl+Shift+I (Windows) / Cmd+Option+I (Mac)
  2. Click the Network tab
  3. Ensure recording is active (red circle icon)
  4. Check Preserve log to capture across navigations
  5. Reproduce the issue or navigate to the page
  6. Right-click any request → Save all as HAR with content
🔷

Microsoft Edge

  1. Open DevTools: press F12 or Ctrl+Shift+I
  2. Click the Network tab
  3. Enable recording (red button)
  4. Check Preserve log
  5. Reproduce the issue or load the page
  6. Click the Export HAR button (download icon) in the toolbar
🦊

Mozilla Firefox

  1. Open DevTools: press F12 or Ctrl+Shift+I
  2. Click the Network tab
  3. Reproduce the issue or navigate to the page
  4. Right-click any request in the list
  5. Select Save All As HAR
  6. Save the file to your computer

📄 What is a HAR file?

A JSON-formatted archive that records all HTTP requests and responses made by your browser — including headers, timings, cookies, and body content.

🔧 Why is it useful?

HAR files help diagnose slow page loads, failed requests, authentication problems, and performance bottlenecks by giving a complete picture of network activity.

⚠️ Sensitive data

HAR files can contain cookies, auth tokens, passwords, and personal data. Treat them as confidential. Never share them publicly or send them to untrusted parties.

🔒 This tool is safe

HAR Analyser processes your file entirely in your browser. Nothing is uploaded. You can even use it offline after the page has loaded.

Privacy

Your Privacy is Non-Negotiable

HAR files can contain sensitive information. We've designed this tool to ensure your data never leaves your control.

🔒

Local Only

All HAR parsing and analysis runs entirely in your browser using JavaScript. Zero server involvement.

🚫

No Uploads

Your file is never transmitted anywhere. It stays on your machine, in memory, until you close or refresh the tab.

🗑️

No Storage

Nothing is written to localStorage, sessionStorage, IndexedDB, or cookies. The page reloads clean every time.

👁️

Open Source

This tool is open source on GitHub. You can inspect every line of code to verify these privacy guarantees.

⚠️ Handle HAR files with care. HAR files may contain authentication tokens, session cookies, API keys, passwords, and personal data. Never share a HAR file publicly, send it to an untrusted party, or upload it to an online analyser you don't trust. This tool is specifically designed so that never needs to happen.
