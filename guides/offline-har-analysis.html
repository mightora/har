Analyse HAR files offline with a single HTML file

Download a standalone HAR analyser in a ZIP. Double-click one HTML file and analyse HTTP Archive logs locally without a server, installation or internet.

If your HAR capture contains internal hostnames, authorisation tokens, cookies or other confidential data, using an offline analysis tool can reduce the risk introduced by third-party scripts and remote processing.

Download and run the offline analyser

  1. Download the Mightora offline ZIP.
  2. Extract the ZIP archive onto your computer.
  3. Double-click har-analyser.html. A modern browser will open the tool.
  4. Choose the HAR file you want to inspect. Results appear locally in the browser.
  5. Optionally export a sanitised report, reviewing it carefully before sharing.

You may also download the standalone HTML directly. There is no executable installer or privileged permission request.

Does it send data anywhere?

The offline edition embeds its JavaScript, CSS and logo. It doesn't include analytics, CDN requests, background synchronisation, telemetry or fetch calls. Captured HAR URLs are displayed only as text and never replayed. The tool can run with your computer disconnected from the internet.

What about the browser?

Opening local HTML is supported by modern versions of Chrome, Edge and Firefox. Browser security rules for local files differ slightly. The offline analyser supports processing directly without requiring a local web server or module imports. You can disconnect from the network as an additional precaution before opening a sensitive capture.

Privacy isn't the same as anonymisation

Your original HAR still contains whatever the capturing browser recorded. The report removes sensitive raw fields, but hostnames and some paths may remain recognisable. For highly sensitive incidents, store, delete and share files in accordance with your organisation's security policies.

Is the download safe to inspect?

Yes: the source is available in the public GitHub repository under the MIT licence. The ZIP contains an HTML file and documentation—not a compiled program. You can open the HTML in a text editor and audit the code.
